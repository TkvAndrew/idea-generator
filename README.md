# 💡 Генератор идей

Веб-приложение на **Python + Streamlit** (дизайн 2026): выбираете категорию — получаете случайную идею.
Нажимайте снова, пока не найдёте ту самую 💫

## ✨ Возможности

- 🌌 Анимированный неоновый фон и глассморфизм (дизайн 2026)
- 🎴 Карточка идеи с анимацией появления
- 🎈 Конфетти при каждой генерации
- 📜 История идей в сворачиваемом блоке
- 📊 Счётчик «поймано» и статистика категорий
- 🧹 Кнопка сброса

## 🗂 Структура

```
vb_python_lesson_2/
├── app.py                  # само приложение
├── .streamlit/config.toml  # тема и настройки
├── requirements.txt        # зависимости
└── PLAN.md                 # план реализации
```

## 🚀 Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Откроется браузер: http://localhost:8501

## 🐍 Как это устроено

- Категории хранятся в **словаре**, идеи — в **списках**.
- Случайная идея выбирается через `random.choice()`.
- Результат и история живут в `st.session_state` (Streamlit перезапускает скрипт при каждом клике).
- Кнопки используют `on_click`-колбэки, чтобы счётчик обновлялся без «отставания на 1».
