# План реализации веб-приложения «Генератор идей» на Streamlit

## Цель
Перенести обычный Python-скрипт (словарь категорий + `random.choice`) в веб-приложение,
где категорию выбирают мышкой в браузере, а идея обновляется по кнопке.

## Итоговая структура файлов
```
vb_python_lesson_2/
├── app.py             # само приложение
├── requirements.txt   # зависимости (streamlit)
└── PLAN.md            # этот план
```

---

## Шаги реализации

### Шаг 1. Установить Streamlit
```bash
pip install -r requirements.txt
```

### Шаг 2. Импорты
```python
import random
import streamlit as st
```
`random` — выбирает идею, `streamlit` — рисует веб-интерфейс.

### Шаг 3. Настройка страницы
```python
st.set_page_config(page_title="Генератор идей", page_icon="💡", layout="centered")
```
Задаёт заголовок вкладки браузера, иконку и ширину контента.
Вызывать **первым** действием Streamlit.

### Шаг 4. Данные
```python
IDEAS = {
    "💻 IT-проекты": ["...", "..."],
    "✍️ Тексты и контент": ["...", "..."],
}
```
Словарь: **ключ** — название категории, **значение** — список идей.
Та же структура, что и в консольной версии.

### Шаг 5. Состояние между перезапусками
```python
st.session_state.setdefault("idea", None)
st.session_state.setdefault("idea_category", None)
st.session_state.setdefault("history", [])
```
**Ключевой момент Streamlit:** при любом клике скрипт выполняется заново с нуля.
Обычная переменная «забудется», поэтому результат и история хранятся в
`st.session_state` (живёт, пока открыта вкладка браузера).

### Шаг 6. Элементы управления
```python
category = st.selectbox("Категория", list(IDEAS.keys()))
generate = st.button("🎲 Сгенерировать идею", type="primary")
clear = st.button("🧹 Очистить")
```
- `st.selectbox` — выпадающий список; возвращает выбранную строку.
- `st.button` — кнопка; возвращает `True` только в том кадре, когда по ней кликнули.
- `st.columns` — раскладывает кнопки в две колонки.

### Шаг 7. Логика генерации
```python
if generate:
    idea = random.choice(IDEAS[category])   # случайная идея выбранной категории
    st.session_state.idea = idea
    st.session_state.idea_category = category
    st.session_state.history.append((category, idea))
```
Каждое нажатие кнопки → новый вызов `random.choice` → новая случайная идея.
История хранится списком пар «категория, идея».

### Шаг 8. Вывод результата
```python
if st.session_state.idea:
    st.success(f"**{st.session_state.idea_category}**")
    st.markdown(f"## {st.session_state.idea}")
else:
    st.info("Пока идеи нет — нажми кнопку")
```
Разные функции дают разный цвет плашки: `st.success` (зелёная),
`st.info` (синяя), `st.markdown` умеет заголовки.

### Шаг 9. История
```python
with st.expander("📜 История идей"):
    for number, (cat, text) in enumerate(reversed(st.session_state.history), start=1):
        st.write(f"{number}. **{text}** — _{cat}_")
```
`st.expander` — сворачиваемый блок; `reversed` показывает свежие идеи сверху.

### Шаг 10. Запуск и проверка
```bash
streamlit run app.py
```
Откроется браузер. Проверяем критерии готовности:
- переключаем все категории — в каждой есть идеи;
- нажимаем кнопку несколько раз — идея может меняться;
- история накапливается, «Очистить» её сбрасывает.

## Возможные улучшения (по желанию)
1. Не повторять предыдущую идею: выбирать из списка без только что показанной.
2. Кнопка «Скопировать идею» (`st.code` + буфер обмена).
3. Добавить поле, чтобы пользователь вводил **свои** идеи (`st.text_input` + `st.session_state`).
4. Разнести данные и интерфейс по файлам: `ideas.py` + `app.py`.
5. Сохранять историю в файл (`json`), чтобы она не терялась после закрытия вкладки.
